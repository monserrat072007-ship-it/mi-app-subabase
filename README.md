# Práctica de Supabase

## Descripción
Aplicación web básica para registrar estudiantes y consultar sus datos utilizando Supabase como base de datos.

## Tecnologías utilizadas
- HTML
- JavaScript
- Supabase
- Visual Studio Code
- Git y GitHub

## Funcionalidades
- Registrar estudiantes con nombre y carrera.
- Guardar los registros en la tabla `estudiantes`.
- Consultar y mostrar los estudiantes registrados.

## Ejecución
1. Instalar Node.js y las dependencias del proyecto.
2. Configurar la URL y la clave pública de Supabase en `index.js`.
3. Abrir `index.html` mediante Live Server en Visual Studio Code.

## Estructura del proyecto
- `index.html`: formulario e interfaz.
- `index.js`: conexión con Supabase y operaciones de registro y consulta.
- `package.json`: configuración y dependencias.
- `.gitignore`: archivos excluidos del repositorio.
